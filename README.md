A deal finder for Black Friday 2026: 30 real deals at Amazon and Best Buy,
each checked on 27 Nov 2026 at 06:10 UTC against the store or the deals source
named on its card. Search, filter by category, store and minimum discount,
sort by biggest discount, biggest saving or lowest price, and open any deal
for its full detail — including the same MacBook Air compared across both
stores. Discounts are computed from the sale and usual prices shown, and
every card carries an honest verdict: new low, strong price, decent saving,
or routine sale.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Hand in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
